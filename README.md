# BSNL FTTH Warangal Streamlit Dashboard

## What this app does
1. Upload `OLT_Wise_Provisioning.xlsx`.
2. Run the existing BSNL processing logic.
3. Download:
   - `FTTH_Warangal_Dashboard.xlsx`
   - `FTTH_Warangal_Dashboard.html`

The BSNL logo and the existing OLT/BBC mappings remain inside the processor.

## Deploy to Streamlit Community Cloud
1. Create a GitHub repository and upload:
   - `app.py`
   - `report_processor.py`
   - `requirements.txt`
2. Open Streamlit Community Cloud.
3. Create a new app from that GitHub repository.
4. Set the main file to `app.py`.
5. Deploy.
6. Share the generated `streamlit.app` URL with users.

No Python installation is needed on the end user's PC.

## Important
The actual public web URL is generated by Streamlit after deployment; it cannot be pre-created inside this ZIP.
